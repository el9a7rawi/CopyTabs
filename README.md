# CopyTabs | ناسخ روابط التبويبات بضغطة واحدة

كل روابط تبويباتك المفتوحة في ملف `TXT` مرقّم بضغطة واحدة — سريع وخاص ويعمل أوفلاين.

```text
1. https://example.com/page1
2. https://example.com/page2
3. https://example.com/page3
```

## ✨ المميزات

| # | الميزة |
|---|--------|
| 1 | نطاق النسخ: النافذة الحالية أو كل النوافذ |
| 2 | تضمين عنوان الصفحة مع الرابط |
| 3 | إزالة الروابط المكررة تلقائيًا |
| 4 | تخطي صفحات النظام (`chrome://`…) |
| 5 | الترتيب: أصلي / أبجدي / حسب الدومين |
| 6 | تنسيق الترقيم: `1.` / `1)` / `-` |
| 7 | اسم ملف مخصص + ختم تاريخ تلقائي |
| 8 | نسخ تلقائي للحافظة بعد التصدير |
| 9 | وضع داكن حقيقي (أسود) + وضع فاتح |
| 10 | سجل آخر 10 تصديرات + إعادة تحميل + مسح |

**إضافات مدمجة:** معاينة حية + بحث قابل للتوسع + تحديد فردي + عدّاد + Badge + قائمة سياق (كليك يمين) + اختصاران (`Ctrl+Shift+U` فتح، `Ctrl+Shift+E` تصدير سريع).

## 🚀 التحميل على كروم (مباشرة من هذا الريبو)

1. حمّل المشروع: **Code → Download ZIP** وفك الضغط (أو `git clone`).
2. افتح `chrome://extensions` وفعّل **Developer mode**.
3. اضغط **Load unpacked** واختر مجلد المشروع.
4. ثبّت الأيقونة 📌 وابدأ: **احفظ كل روابطك الآن**.

## 🗂️ الهيكل

```text
├── manifest.json      ← إعلان Manifest V3
├── popup.html/css/js  ← الواجهة العربية RTL
├── background.js      ← Service Worker (شارة + تصدير سريع)
├── options.html/js    ← صفحة الإعدادات (مرآة)
└── icons/             ← 16 / 32 / 48 / 128
```

## 🔒 الخصوصية

- يعمل **أوفلاين بالكامل** — لا يرسل أي بيانات لأي سيرفر.
- أقل صلاحيات ممكنة: `tabs` + `storage` + `contextMenus` + `downloads`.
- كل الإعدادات والسجل محفوظة محليًا على جهازك (`chrome.storage.local`).

## 🛠️ التطوير

لا يوجد build ولا اعتماديات — عدّل الملفات ثم اضغط **Reload** من `chrome://extensions`.

```powershell
node --check popup.js
node --check background.js
node --check options.js
python3 -c "import json; json.load(open('manifest.json')); print('manifest OK')"
```
