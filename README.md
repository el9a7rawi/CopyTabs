## 🤔 المشكلة

الباحث اللي فاتح 15 مصدر، والطالب اللي مجمّع شروحات، والمسوّق اللي بيراجع منافسين — كلهم بيضيعوا وقت في نسخ الروابط **رابط رابط**، أو بيضيعوا الجلسة كلها لما المتصفح يتقفل. حلول النسخ اليدوي بطيئة، والإضافات الأجنبية معقدة ومليانة صلاحيات.

## ✅ الحل

**CopyTabs** زر واحد في شريط كروم يجمع روابط كل تبويباتك المفتوحة ويصدّرها في ملف `.txt` مرقّم **+ نسخة فورية في الحافظة + معاينة حية قبل التصدير**. بدون حساب، بدون إنترنت، وبدون أي بيانات بتخرج من جهازك.

## ⚡ 3 خطوات فقط

1. **ثبّت** الإضافة من هذا الريبو (دقيقتان — الطريقة بالأسفل).
2. **افتح** تبويباتك و**خصّص** التصدير من 9 خيارات (النطاق، الترتيب، الترقيم…).
3. **اضغط «احفظ كل روابطك الآن»** — الملف اتحمّل والروابط في حافظتك.

## ✨ المميزات العشر

| # | الميزة | الفائدة لك |
|---|--------|-----------|
| 1 | نطاق النسخ (النافذة الحالية / كل النوافذ) | انسخ جلستك الحالية أو كل شغلك المفتوح |
| 2 | تضمين عنوان الصفحة مع الرابط | ملف مفهوم بدون ما تفتح كل رابط |
| 3 | إزالة الروابط المكررة تلقائيًا | قائمة نضيفة من أول مرة |
| 4 | تخطي صفحات النظام (`chrome://`…) | مفيش روابط ميتة في ملفك |
| 5 | الترتيب (أصلي / أبجدي / حسب الدومين) | نظّم القائمة بالطريقة اللي تناسبك |
| 6 | تنسيق الترقيم (`1.` / `1)` / `-`) | يتوافق مع أي محرر أو مستند |
| 7 | اسم ملف مخصص + ختم تاريخ تلقائي | `tabs-links-2026-10-13.txt` — رتّب أرشيفك بسهولة |
| 8 | نسخ تلقائي للحافظة | الصق فورًا في واتساب / تيليجرام / ملاحظاتك |
| 9 | سجل آخر 10 تصديرات | ارجع لأي نسخة وحمّلها مجددًا بضغطة |
| 10 | وضع داكن حقيقي + فاتح | مريح لعينك ليل ونهار |

**إضافات مدمجة:** معاينة حية + بحث قابل للتوسع 🔍 + تحديد فردي لكل رابط + عدّاد + شارة بعدد التبويبات + قائمة سياق (كليك يمين على الأيقونة) + اختصارا لوحة المفاتيح (`Ctrl+Shift+U` للفتح، `Ctrl+Shift+E` للتصدير السريع).

## 🚀 التحميل على كروم

1. حمّل المشروع: **Code ← Download ZIP** وفك الضغط (أو عبر `git clone`).
2. افتح `chrome://extensions` وفعّل **Developer mode** (وضع المطوّر).
3. اضغط **Load unpacked** واختر مجلد المشروع.
4. ثبّت الأيقونة 📌 من شريط الأدوات — جاهز.

> **ملاحظة:** المشروع Vanilla JS بالكامل — لا build ولا اعتماديات. أي تعديل = اضغط **Reload** من صفحة الإضافات فقط.

## 🔒 الخصوصية أولًا

- ✅ يعمل **أوفلاين بالكامل** — صفر طلبات شبكة.
- ✅ **أقل صلاحيات ممكنة**: `tabs` + `storage` + `contextMenus` + `downloads` فقط — لا تتبع، لا سيرفرات.
- ✅ كل الإعدادات والسجل محفوظة **محليًا على جهازك** (`chrome.storage.local`).
- ✅ كود مفتوح 100% — راجعه بنفسك قبل التثبيت.

## 🛠️ للمطورين

```text
├── manifest.json      ← إعلان Manifest V3 (أقل صلاحيات)
├── popup.html/css/js  ← الواجهة العربية RTL (خط Cairo + Tajawal)
├── background.js      ← Service Worker (شارة العدد + تصدير سريع)
├── options.html/js    ← صفحة الإعدادات (مرآة بنفس المفاتيح)
├── assets/screenshots ← لقطات الواجهة
└── icons/             ← 16 / 32 / 48 / 128
```

**أهم القواعد المعمارية** (التفاصيل الكاملة في [`AGENTS.md`](AGENTS.md)):

- Manifest V3 حصرًا، ولا سطر `eval` ولا `innerHTML` مع بيانات المستخدم (`textContent` فقط).
- لا كود من CDN ولا content-scripts — سطح هجوم شبه معدوم.
- التحقق السريع قبل أي تسليم:

```powershell
python3 -c "import json; json.load(open('manifest.json')); print('manifest OK')"
```

## ❓ أسئلة شائعة

**هل يعمل بدون إنترنت؟**
نعم بالكامل — ما عدا تحميل خط Cairo من جوجل (وله بديل محلي تلقائي).

**هل يجمع بياناتي؟**
لا. لا يوجد أي كود شبكة في الإضافة — افحص `popup.js` و`background.js` بنفسك.

**ملف TXT لا يتحمّل؟**
تأكد من صلاحية التنزيلات في كروم، وجرّب زر «تحميل TXT» — يوجد مسار بديل مدمج يعمل دون صلاحيات إضافية.

**أريد ترقيمًا مختلفًا؟**
من «خصّص التصدير ← تنسيق الترقيم»: `1.` أو `1)` أو `-`.
